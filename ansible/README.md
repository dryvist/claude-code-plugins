# ansible

Repository conventions for Ansible playbooks, roles, inventories, and collections.

## What it covers

- Repository ownership and documented layout
- Lint, syntax, and Molecule checks
- Shared workflow and dependency versioning
- Runtime secret handling

## Installation

```bash
claude plugins add jacobpevans-cc-plugins/ansible
```

## Usage

Use `/ansible-conventions` when changing or reviewing an Ansible repository.
