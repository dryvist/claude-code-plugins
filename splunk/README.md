# splunk

Repository conventions for Splunk apps, packages, pipelines, and deployment automation.

## What it covers

- Documented app and deployment ownership
- Package validation and repository-specific checks
- Shared workflow and dependency versioning
- Runtime secret handling

## Installation

```bash
claude plugins add jacobpevans-cc-plugins/splunk
```

## Usage

Use `/splunk-app-conventions` when changing or reviewing a Splunk app or deployment repository.
