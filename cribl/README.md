# cribl

Repository conventions for Cribl Stream and Edge packs.

## What it covers

- Pack-specific versus template-owned files
- Structure validation, YAML lint, and test commands
- Shared workflow and release conventions
- Runtime secret handling

## Installation

```bash
claude plugins add jacobpevans-cc-plugins/cribl
```

## Usage

Use `/cribl-pack-conventions` when changing or reviewing a Cribl pack.
